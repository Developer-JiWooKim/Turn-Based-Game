# 시스템 흐름도 (System Flowcharts & Logic Specifications)

## 시스템 이름: Battle System(BattleSystem.jpg 참고)

<img src="BattleSystem_Flowchart.jpg">

### 1. 시작 조건
- Run Setup System 완료 후 진입
- 직전 스테이지 클리어 후 다음 스테이지로 이동 시

---

### 2. 입력 정보
- Stage_Index: 현재 조우 번호
- Party_Data: 파티원 목록, 현재 HP, 적용 중인 버프/디버프/시너지
- Monster_Spawn_Pattern: 스폰 패턴 (1~5 Stage: 수동 / 6+ Stage: 무작위 풀 / 5의 배수: 보스)
- Unit_Stats: 유닛별 SPD, ATK, DEF, CRIT Rate/DMG, RES, 고유 스킬 쿨타임
- Current_Turn_Owner: 현재 턴을 소유한 유닛 정보 (Player / Enemy)

---

### 3. 기본 흐름
- 1) [조우 진입 & 스폰] Stage_Index에 따른 몬스터 스폰 연출
- 2) [턴 정렬] 모든 생존 유닛의 SPD 수치를 비교하여 행동 순서(Queue) 정렬
- 3) [턴 수행] Queue 순서대로 행동 실행
    - Player Turn: 플레이어 입력(타겟팅/공격/스킬)
    - Enemy Turn: 적 AI 행동 실행
- 4) [턴 순환] Queue 내 전원 행동 완료 시 턴 종료 → SPD 재정렬 후 다음 턴 시작
- 5) [조우 클리어] 적 전멸 시 전투 종료 → `Roguelike Reward Choice System` 으로 이행
- 6) [다음 진행] `Roguelike Reward Choice System`에서 데이터/제어 이관받아 다음 스테이지 스폰 준비 상태로 진입

---

### 4. 조건 분기
- [분기 A] 클리어한 스테이지가 5의 배수(보스 조우)
  - 결과: 선택지 선택 전 자동 저장(Party_Data, Stage_Index, Weight 등)
    
- [분기 B] 클리어한 스테이지가 5의 배수가 아님
  - 결과: 별도 저장 없이 즉시 다음 스테이지로 진행
 
---

### 5. 예외 상황 및 처리
- [예외 1] 전투 중 아군 캐릭터 HP가 0 도달 (사망)
  - 처리: 해당 캐릭터 파티에서 즉시 영구 제거. 이로 인해 파티 시너지 조건 미달 시 시너지 효과 즉시 해제. 남은 파티원으로 전투 계속 진행.
    
- [예외 2] 아군 파티 전원 사망 (전멸 / Game Over)
  - 처리: 전투 즉시 종료 → 결과 화면 출력 → 세이브 데이터 영구 삭제 → 최고 기록 갱신 → 최초 10 스테이지 단위 돌파에 따른 Meta_Point 지급 → 타이틀 복귀
    
- [예외 3]: 플레이어 턴 중 Pause 메뉴에서 [배틀 중단] 버튼 클릭
  - 처리: 확인 팝업 출력(`"현재 진행은 저장되지 않으며, 마지막 저장 지점부터 시작합니다."`) → 확인 시 마지막 Auto-Save 지점 데이터 유지 상태로 전투 중단 후 타이틀 복귀
    
- [예외 4] 적 턴 중 Pause 메뉴 진입
  - 처리: Pause UI 창은 열리나, 로직 꼬임 방지를 위해 [배틀 중단] 버튼을 비활성화(Disabled) 처리하여 클릭 불가

---

### 6. 종료 조건 및 출력
- 종료 조건: 파티 전멸 / 배틀 중단 확정 / 최종 콘텐츠 종료
  
- 플레이어에게 보여줄 결과
  - 일반 클리어: 선택지 UI (3종) 출력 및 선택 스탯/영입 반영 결과
  - 보스 클리어: 자동 저장 알림 (짧은 시각 피드백) 후 일반 클리어와 동일
  - 배틀 중단: 중단 확인 팝업 → 타이틀 화면으로 이행
  - 전멸(Game Over): Final Result 화면 출력 (도달 스테이지, 최고 기록 갱신 여부)


---

## 시스템 이름: Roguelike Reward Choice System

### 1. 시작 조건
- Battle System 내에서 현재 스테이지의 모든 몬스터 HP가 0 도달 (적 전멸 / 스테이지 클리어)

- 아군 전투 상태이상(도트 피해, 기절, 버프/디버프 등) 즉시 전체 해제 후 진입

- 보스 스테이지였다면 클리어 시점 자동 저장 후 진입

---

### 2. 입력 정보
- Stage_Index: 현재 클리어한 스테이지 번호

- Trait_Weight_Data: 플레이어가 성향 포인트로 설정한 선택지 유형별 가중치 (Weight)

- Party_Data: 현재 파티원 목록 및 파티원 수 (최대 4명)

- RoguelikeChoice_Table: 선택지 효과, 기본 가중치, Parameter 값이 정의된 데이터 테이블 (ID 5001~)

---

###  3. 기본 흐름
- 1) [상태 해제 & 가중치 산출] 전투 상태이상 해제 후, Trait_Weight_Data 및 스테이지 수치를 바탕으로 선택지별 최종 등장 가중치 연산

- 2) [선택지 3종 추첨] 연산된 가중치를 적용하여 중복 없는 무작위 선택지 3종 비복원 추첨

- 3) [UI 출력 & 대기] 선택지 카드 3종을 UI 화면에 출력하고 플레이어의 입력(마우스 클릭 / 방향키 / Space / Enter) 대기

- 4) [보상 선택 & 반영] 플레이어가 선택한 1종의 보상 효과 즉시 적용

  - 스탯 강화 / 회복: 즉시 파티 스탯 가산 또는 HP 회복

  - 캐릭터 영입: 신규 캐릭터 추가 (파티 4명 풀 상태일 경우 교체 대상 UI 출력 후 대체 확정)

  - 적 디버프 예약: 다음 1회 스테이지 적용 예약 (배율 곱연산 누적 또는 확정 기절 1턴)

- 5) [진행 및 이행] Stage_Index += 1 처리 및 플레이어 차분 성장 수치 파티 반영 후 다음 스테이지 Battle System 진입

---

### 4. 조건 분기
- [분기 A] 클리어한 스테이지가 5의 배수 (보스 스테이지: Stage_Index % 5 == 0)
  - 결과: 선택지 결과 반영 완료 후, Auto-Save 로직 실행 (Party_Data, Stage_Index, Trait_Weight_Data, Debuff_Reserve 데이터 쓰기) $\rightarrow$ 시각적 자동 저장 알림 출력 후 다음 스테이지 진입

- [분기 B] 클리어한 스테이지가 5의 배수가 아님 (Stage_Index % 5 != 0)
  - 결과: 자동 저장 스킵 후 즉시 다음 스테이지 진입

---

### 5. 예외 상황 및 처리
- [예외 1] 파티원이 이미 4명 풀(Full)인 상태에서 [캐릭터 영입] 선택지 선택
  - 처리: 영입 확정 전 [파티원 교체 선택 UI] 팝업 출력 $\rightarrow$ 퇴출할 기존 파티원 1명을 선택하여 교체 확정 (취소 클릭 시 선택지 선택 UI 단계로 안전하게 복귀)

- [예외 2] 모든 선택지의 최종 가중치 합이 0 이하인 상황 발생 ($\sum W_k \le 0$)
  - 처리: 가중치 추첨 실패 예외 방지를 위해 RoguelikeChoice_Table 내 유효 선택지 중 균등 확률(Equal Weight)로 3종 비복원 추첨 대체

- [예외 3] 선택지 디버프(적 약화) 선택 후 보스 조우 진입 시
  - 처리: 다음 1회 스테이지 몬스터 스폰 시 스케일링 연산 마지막 단계에서 예약된 디버프 배율 곱연산 즉시 적용 (Enemy Stun 선택 시 1턴 확정 기절 부여)

---

### 6. 종료 조건 및 출력

- 종료 조건: 보상 반영 및 다음 스테이지(Stage_Index + 1) Battle System 진입 시점

- 플레이어에게 보여줄 결과

  - 보상 선택 UI: 무작위 3종 선택지 카드 (카드 클릭 시 연출 및 선택 완료 피드백)

  - 영입 교체 UI (필요 시): 현재 파티원 4명의 정보가 담긴 교체 대상 지정 UI

  - 보스 클리어 시: 자동 저장 아이콘/알림 연출 출력

---

## 시스템 이름: Run Setup System

### 1. 시작 조건
- 게임 실행 후 타이틀 화면 진입

---

### 2. 입력 정보
- Save Data 존재 여부(단일 슬롯)
- 보유 영구 포인트(`선택지 성향 포인트`) 수치
- 6종 캐릭터 데이터

--- 

### 3. 기본 흐름
- 1) [타이틀 화면] UI 출력 (`New Expedition` / `Continue` 버튼)
- 2) [캐릭터 선택 화면] 진입 (6종 중 1명 선택 → 3D 모델링 프리뷰 및 기본 스탯 UI 출력)
    - 선택적 액션: UI내 `성향` 버튼 클릭시 성향 포인트 배분 팝업이 출력 → 보유 포인트를 소비하여 선택지 유형별 가중치 Weight 설정 가능
- 3) [전투 진입] `시작` 버튼 클릭 → `Battle System`으로 상태 이행

---

### 4. 조건 분기
- [분기 A] `Continue` 선택 (세이브 데이터 존재 시)
  - 캐릭터 선택 및 성향 배분 단계 스킵
  - 저장된 파티 구성/스탯/선택지 가중치 데이터 복원 → 마지막 클리어 보스의 다음 스테이지로 `Battle System`진입(예를 들어 25스테이지 보스를 깼으면 26스테이지 시작)
 
- [분기 B] `New Expedition` 선택
  - 기본 흐름(2 → 3) 정상 진행
 
---

### 5. 예외 상황 및 처리
- [예외 1] 캐릭터 선택 화면에서 뒤로가기 버튼 클릭
  - 처리: 타이틀 화면으로 복귀
    
- [예외 2] 세이브 데이터가 존재하는데 `New Expedition` 진행 후 [전투 시작] 클릭 (캐릭터 선택, 성향 배분 완료 후 전투 시작 버튼 클릭 시점)
  - 처리: 경고 팝업 출력(`"기존 진행 데이터가 삭제됩니다. 계속하시겠습니까?"`)
    - 확인 선택: 기존 세이브 데이터 즉시 삭제 후 `Battle System` 진입
    - 취소 선택: 팝업 닫힘 및 캐릭터 선택 화면 유지를 통해 입력 보호

- [예외 3] 성향 포인트 배분 미진행 시
  - 처리: 가중치 없이 진행

---

### 6. 종료 조건 및 출력
- 종료 조건: Battle System으로 씬(Scene) 전환 시점
  
- 플레이어에게 보여줄 결과
  - New Expedition: 신규 파티 + 배분된 선택지 가중치가 적용된 1 스테이지 진입
  - Continue: 복원된 파티/스탯/가중치가 반영된 해당 스테이지 진입
